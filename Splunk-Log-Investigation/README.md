# Splunk Log Investigation

## Objective
This lab focuses on analyzing system and security logs using Splunk to identify suspicious activities, failed login attempts, and possible threats.

## Tools Used
- Kali Linux
- Splunk
- Sample log files

## Tasks Performed
- Imported log files into Splunk
- Searched for failed login attempts
- Investigated suspicious IP addresses
- Reviewed event timestamps
- Correlated security events

## Findings
- Multiple failed login attempts were observed
- Source IP addresses were identified
- Suspicious event patterns were documented

## Skills Demonstrated
- SIEM log analysis
- Event correlation
- Threat investigation
- Incident detection

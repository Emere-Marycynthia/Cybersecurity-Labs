# Incident Response Lab

## Objective
This lab documents the process of identifying, analyzing, and responding to cybersecurity incidents.

## Phases Covered
- Identification
- Containment
- Eradication
- Recovery
- Lessons learned

## Tasks Performed
- Reviewed suspicious alerts
- Investigated possible compromise
- Documented response steps
- Suggested remediation actions

## Skills Demonstrated
- Incident handling
- Threat analysis
- Documentation
- Security response workflow

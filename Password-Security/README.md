# Password Security Lab 

## Objective
This lab focuses on password security, hash identification, and password cracking techniques for educational purposes.

## Tools Used
- Kali Linux
- John the Ripper
- Hashcat

## Tasks Performed
- Identified hash types
- Tested password complexity
- Cracked sample password hashes
- Reviewed password strength policies

## Skills Demonstrated
- Password auditing
- Hash analysis
- Security best practices
- Access control awareness
